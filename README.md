# Flash-Card-App-with-Spaced-Repitetion
This project is a web-based flashcard learning application inspired by modern spaced repetition systems\
like Anki.\
The application helps users study efficiently by automatically scheduling flashcards based on memory\
performance.\
Instead of showing cards randomly, the system uses a scheduling algorithm to determine:\
● which card should appear next,\
● how difficult the card is for the user,\
● and when the card should be reviewed again.\
The project is developed using:\
● HTML\
● CSS\
● Vanilla JavaScript\
No backend or frameworks are required\
